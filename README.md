# Actividad 3
Original de Pacman.py

## Descripción
Pacman recorre el laberinto comiendo los puntos mientras los fantasmas lo persiguen.

## Cómo se usa
- Se mueve a pacman con flechas del teclado.
- Hay que comer las galletas sin que te alcance el fantasma.
