# Actividad 3
Original de Pacman.py

## Descripción
Pacman recorre el laberinto comiendo los puntos mientras los fantasmas lo persiguen.

## Cómo se usa
- Se mueve a pacman con flechas del teclado.
- Hay que comer las galletas sin que te alcance el fantasma.

## Cambios realizados
- Se cambio el diseño del tablero abriendo algunas paredes (Edgar).
- Se aumentó la velocidad de los fantasmas de 5 a 10 (Edgar).
- Los fantasmas eligen la dirección más cercana a pacman al chocar con una pared (Ulises).
- Se corrigió el estilo PEP 8 del código de los fantasmas (Edgar).
